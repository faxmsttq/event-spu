# SPU Event — คำอธิบายโค้ดแต่ละไฟล์

เว็บรวมกิจกรรมของมหาวิทยาลัย เขียนด้วย HTML, CSS และ JavaScript ล้วน ยังไม่มีหลังบ้าน
ข้อมูลทั้งหมด (ผู้ใช้ กิจกรรม คำขอ ประกาศ) เก็บไว้ใน **localStorage** ของเบราว์เซอร์

แต่ละหน้าเป็นไฟล์ HTML 1 ไฟล์ โค้ด JavaScript ของหน้านั้นอยู่ใน `<script>` ท้ายไฟล์
ส่วนโค้ดที่หลายหน้าใช้ร่วมกันอยู่ใน `js/common.js`

---

## ไฟล์กลาง

| ไฟล์ | หน้าที่ |
|---|---|
| `css/style.css` | หน้าตาของทุกหน้า: สี ฟอนต์ ไอคอน ปุ่ม การ์ด ฟอร์ม อนิเมชัน และการจัดหน้าบนมือถือ (เมนูย้ายไปด้านล่างเมื่อจอแคบ) |
| `js/common.js` | โค้ดที่ทุกหน้าใช้ร่วมกัน (ดูรายละเอียดด้านล่าง) |
| `js/lang.js` | ปุ่มเปลี่ยนภาษา ไทย / English มีตารางคำแปล `EN` ถ้าเลือกภาษาอังกฤษ จะเปลี่ยนข้อความบนหน้าเป็นคำแปลให้อัตโนมัติ |

### ใน `js/common.js` มีอะไรบ้าง

- **ข้อมูลตัวอย่าง** — `SAMPLE_EVENTS` (กิจกรรม), `SAMPLE_REQUESTS` (คำขอ), `SAMPLE_NEWS` (ประกาศ), บัญชีตัวอย่าง (นักศึกษา แอดมิน อาจารย์), `FACULTIES` (รายชื่อคณะ)
- **อ่าน/บันทึกข้อมูล** — `getEvents()` / `saveEvents()`, `getRequests()` / `saveRequests()`, `getUsers()` / `saveUsers()`, `getNews()` / `saveNews()` แปลงข้อมูลเป็น JSON แล้วเก็บใน localStorage
- **ผู้ใช้และสิทธิ์** — `getCurrentUser()`, `login()`, `logout()`, `isAdmin()`, `isStaff()`, `requireLogin()` (ยังไม่ล็อกอินจะพาไปหน้า login), `requireAdmin()`, `requireStaff()`
- **กิจกรรม** — `isOpen()` (เปิดรับสมัครไหม), `isPast()` (จบแล้วไหม), `isPublished()` (แอดมินอนุมัติโพสต์แล้วไหม), `facultyAllowed()` (คณะนี้ลงทะเบียนได้ไหม), `deleteEvent()`
- **คำขอจัดกิจกรรม** — `canReview()` (ใครพิจารณาคำขอนี้ได้), `reviewRequest()` (อนุมัติ/ไม่อนุมัติ), `reviewCardHTML()` (การ์ดคำขอในหน้าแอดมินและหน้าอาจารย์)
- **สร้าง HTML ที่ใช้ซ้ำ** — `cardHTML()` (การ์ดกิจกรรม), `posterHTML()`, `badgeHTML()` (ป้ายสถานะ), `newsCardHTML()` (การ์ดประกาศ)
- **ตัวช่วยอื่นๆ** — `thaiDate()` (แปลงวันที่เป็นแบบไทย), `safe()` (กันข้อความที่ผู้ใช้พิมพ์กลายเป็น HTML), `resizeImage()` (ย่อรูปก่อนเก็บ), `showToast()` (ข้อความแจ้งเตือนด้านล่างจอ), `showFormError()` (ข้อความ error ในฟอร์ม)

| `event.html` | รายละเอียดกิจกรรม 1 อัน (`event.html?id=e1`): เข้าร่วม / ยกเลิก บันทึกไว้ ลงปฏิทิน แชร์ลิงก์ แบบฟอร์มสมัคร ผู้ติดต่อ ถ้าเป็นคนสร้างหรือแอดมินจะเห็น "เครื่องมือผู้จัด" (รายชื่อผู้สมัคร ดาวน์โหลด Excel ปิดรับสมัคร ลบ) |

| `mine.html` | ของฉัน: แท็บกำลังจะมา / เข้าร่วมแล้ว / สร้างไว้ |
| `notifications.html` | แจ้งเตือน: กิจกรรมที่ใกล้ถึง สถานะคำขอ สถานะกิจกรรมที่รออนุมัติ |
| `profile.html` | โปรไฟล์: เปลี่ยนรูป แก้ชื่อ เปลี่ยนรหัสผ่าน ตั้งค่าความเป็นส่วนตัว ข้อมูลติดต่อแอดมิน ออกจากระบบ ลบบัญชี (รหัสนักศึกษา คณะ ชั้นปี แก้เองไม่ได้ ต้องให้แอดมินแก้) |
| `news.html` | รายละเอียดประกาศ 1 อัน (`news.html?id=n1`) |

### ขั้นตอนสร้างกิจกรรม (3 หน้า)

| ไฟล์ | หน้าที่ |
|---|---|
| `requests.html` | รายการคำขอของฉัน พร้อมแถบสถานะ กำลังส่ง → ดำเนินการ → อนุมัติ / ไม่อนุมัติ |
| `request.html` | ฟอร์มยื่นคำขอถึงคณบดี: ชื่อ รายละเอียด วันเวลา สถานที่ ผู้จัด ผู้รับผิดชอบค่าใช้จ่าย จำนวนคน และคณะที่ลงทะเบียนได้ (ใช้แก้ไขแล้วส่งใหม่ได้ด้วย) |
| `create.html` | หลังคำขออนุมัติแล้ว: ใช้ข้อมูลจากคำขอ กรอกเพิ่มแค่หมวดหมู่ โปสเตอร์ ลิงก์ฟอร์ม ผู้ติดต่อ แล้วส่งให้แอดมินอนุมัติโพสต์ |

## ลำดับการทำงานตั้งแต่ยื่นคำขอจนกิจกรรมโพสต์

1. นักศึกษายื่นคำขอที่ `request.html`
2. อาจารย์ของคณะนั้น (`review.html`) หรือแอดมิน (`admin.html`) อนุมัติคำขอ
3. นักศึกษากรอกข้อมูลเพิ่มที่ `create.html` แล้วส่ง → กิจกรรมสถานะ "รอแอดมินอนุมัติ"
4. แอดมินอนุมัติโพสต์ที่ `admin.html` แท็บ "รออนุมัติโพสต์"
5. กิจกรรมแสดงใน `events.html` และเปิดรับสมัคร
